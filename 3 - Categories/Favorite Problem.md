# Summary Structure
1. *The Bottom Line (50 words):* current best answer or the core synthesis of the positions; equivalent to explaining to a stranger in 30 seconds
2. *Details (150-350 words):* summarize the different viewpoints, examples and reasoning
3. *The Remaining Gaps (50 words):* future work, missing data, incomplete model
