- *Notation:* $A \subseteq B$: every element of A is also an element of B
- *Example:*
	- $\mathbb{N} \subseteq \mathbb{Z} \subseteq \mathbb{Q} \subseteq \mathbb{R}$
	- $\emptyset \subseteq$ any set
	- $\forall$ set $S, S \subseteq S$
