- *Definition:* a user-defined data type that stores a value from a fixed set of named constants
	- Each enum constant is mapped to an integer value (similar to [[array]] index)
- *Example:* `enum Day { SUN, MON, TUE, WED, THU , FRI, SAT};`

| Enum constant | Integer value |
| ------------- | ------------- |
| SUN           | 0             |
| MON           | 1             |
| TUE           | 2             |
| WED           | 3             |
| THU           | 4             |
| FRI           | 5             |
| SAT           | 6             |
