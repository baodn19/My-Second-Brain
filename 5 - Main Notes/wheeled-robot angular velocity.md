# Overview
- *Definition:* robot angular velocity around [[instantaneous center of curvature (ICC)]].
$$
\omega  = \frac{v_r - v_l}{d}
$$
# Variables
- $v_{l}$: [[left wheel linear velocity]]
- $v_{r}$: [[right wheel linear velocity]]
- d: distance between wheels (axis length)
