# Structured evaluation
- *Signal areas:* scope, ownership, ambiguity, perseverance, conflict resolution, growth, communication, leadership
	- How to handle difficult things, break down task
	- Push through challenge
	- Conflict make us better, resolve in healthy way
	- growth mindset, learn from your experience
	- engage with others
	- leadership: amazon 16 leadership values
- *Preparation*: prepare core stories and practice telling them -> Go to the mode of talking about yourself
	- Practice pairing stories with the questions u might get
	- Do a lot of mock interview
- *Real time*: decode, select, deliver
	- Decode: understand the question
	- Select: pick the right stories
	- Deliver: practice in deliveries
# The Process
- *Step 1:* identify stories
	- Identify: title & setting -> context overview -> Action Inventory -> Results (measurable metric) & Impact (its overall affect on everything) -> Learning -> Signal area tag
	- 3-4 core stories: high-impact, challenging, leadership, learning exp, career transitions
- *Step 2:* extract meaningful details
	- CARL: Context **Action** (biggest) Results Learning
- *Step 3:* formulate stories based on CARL
- *Step 4:* big 3 questions
	- Tell me about yourself: set the stage
	- Favorite project: biggest scope, impact, personal involvement
	- Conflict story: highest stakes, deepest involvement, you were right
- *Step 5:* prepare meaningful questions
- *Step 6:* practice with yourself, AI
