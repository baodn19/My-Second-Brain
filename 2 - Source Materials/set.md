- *Definition:* a collection of objects, called elements of the set; order isn't important
- *Example:* 
	- {1, 2, 3}
	- {0, {0, 1}, {0, 1, 2}}
	- $\mathbb{N}, \mathbb{Z}, \mathbb{Z}_{+}, \mathbb{R}$
- *Notation:* $x \in A$: x is an element of A
			$x \not\in A$: x isn't in A
