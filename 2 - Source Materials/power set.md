- *Definition:* the [[set]] of [[subset]]s of a set A
- *Notation:* $P(A) = \{B|B\subseteq A\}$
- *Example:* A = {0, 1} $\implies P(A) = \{\emptyset,A,\{0\},\{1\}\}$
- *Theorem:* If |A| < infinity $\implies|P(A)|=2^{|A|}$
