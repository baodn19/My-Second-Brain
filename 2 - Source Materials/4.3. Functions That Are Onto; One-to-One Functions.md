# Practice
- *1a:* If f [[onto (surjective) function]]: $f:\mathbb{R}\to \mathbb{R},f(x)=\frac{1}{2}x+6$
		*want:* $\forall a\in \mathbb{R},\exists b\in \mathbb{R}:f(b)=a$
		$\iff \frac{1}{2}b+6 \iff b=2(a-6) \implies b\in \mathbb{R}$   $\Box$
- *1c:* If f onto (surjective) function: $f:\mathbb{N}\to \mathbb{N}\times \mathbb{N},f(x)=(x,x)$
		not onto: $(m,n)\in \mathbb{N}\times \mathbb{N}, m\neq n$ but $(m,n)\not\in range(f)$
- *2a:* If f [[one-to-one (injective) function]]: $f:\mathbb{R}\to \mathbb{R},f(x)=\frac{1}{2}x+6$
		Take $a,b\in \mathbb{R}:$ if $f(a)=f(b)\implies a=b$
		Assume: f(a) = f(b); want: a=b
		$\iff \frac{1}{2}a+6=\frac{1}{2}b+6\implies a=b$   $\Box$
- *2j:* If f one-to-one (injective) function: $f:\mathbb{R}\to[1,\infty),f(x)=x^2+1$
		Take: $x, y \in \mathbb{R}$. Assume f(x) = f(y). *want:* x = y
		$\implies x^2+1=y^2+1\implies x^2=y^2\implies x=\pm y\implies f$ not 1-1  $\neg$
