- *Definition:* a collection of items follow the [[last-in first-out (LIFO)]] rule; formally known as an [[abstract data type (ADT)]]
- *Operation:*
	- *`push(e)`:* add element to the top
	- *`pop()`:* remove top element
	- *`top()`:* view top element without removing it
	- *`size()`*: # of elements
	- *`empty()`*: check if stack is empty
