- *Definition:* a [[set]] of [[equivalence class]]es is a partition of a set A
- *Theorem:* A is a set
	1. If $R \subseteq A\times A$ is an [[equivalence relation]], then $S=\{B\subseteq A|\exists a \in A$ s.t $B=[a]\}$
	2. If $S\subseteq \mathscr{P}(A)$ is a partition, then $R: xRy$ iff $\exists B\in S:x,y\in B$ and R is an equivalence relation
