- *Definition:* the number of ways to choose $k$ unordered items from a set of $n$ possibilities. It is commonly read as "$n$ choose $k$"
- *Formula:* 
	-  **$n$**: Total number of items.
	- **$k$**: Number of items to choose.
$$\binom{n}{k} = \frac{n!}{k!(n-k)!}$$
