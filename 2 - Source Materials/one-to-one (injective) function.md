- *Definition:* A for $f:A\to B$ if $\forall y \in B$, there is **at most one** $x \in A:f(x)=y$
- *Example:* if $f(x_{1})=f(x_{2})\implies x_{1} = x_{2}$
	- *Contrapositive:* if $x_{1} \neq x_{2}\implies f(x_{1})\neq f(x_{2})$
- *If f is not 1-1:* $x_{1}\neq x_{2}\wedge f(x_{1})=f(x_{2})$
