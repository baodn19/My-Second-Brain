- *Application (discrete random variable):* Models the number of [[Bernoulli distribution]] trials ($x$) required to achieve a specified target number of successes ($r$).
- *Example:* Determining the number of attempts a robotic manipulator requires to successfully grasp an object exactly 10 times.
