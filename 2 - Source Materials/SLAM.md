- *Abbreviation:* Simultaneous Localization and Mapping
- *Definition:* the process by which a robot builds a map of the environment and, and simultaneously, uses this map to compute its location
- [[chicken-or-egg problem:]] 
	- A map is needed for localizing a robot 
	- A pose estimate is needed to build a map
