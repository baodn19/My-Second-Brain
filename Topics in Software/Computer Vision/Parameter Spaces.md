# Hough Space
## Line
- *Model:* rho-theta parameterization
	- rho: the perpendicular distance from the line to the origin
	- theta: the angle this perpendicular line makes with the X axis
- Parameterization allows for vertical lines and avoids infinite slopes

## Circle
- The Hough space is 3D: (center_x, center_y, radius)
- Each point in this space represents a possible circle in the original image
